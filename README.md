# README for code and data of Integrating biodiversity in post-growth scenarios

## Introduction

This repository provides the list of studies reviewed and the verbatim selected for the NFF classification.

## Prerequisites

None

## Contents 

### Folder structure

`Supplementary1`: list of the 83 studies reviewed with 5 columns (`ID`: paper identification to link with figures in the manuscript, `Title`, `Authors`, `Type` and `DOI or url`)
`Supplementary2`: list of the citations related to specific values of nature in the 16 studies referring to biodiversity or direct drivers of biodiversity. First table with 17 rows and 3 columns (`ID`: paper identification, `NFF`: specific value(s) of nature in the Nature Future Framework, `Citations`: comprehensive citations referring to biodiversity or direct drivers of biodiversity). Second table with 4 rows and 3 columns (lignes 20-24) (`Specific values of nature`: names of the values, `Definition`, `References`: for the definitions)

### File formats 

Data are provided both in `csv`.

## Usage

Each file can be opened independently.
